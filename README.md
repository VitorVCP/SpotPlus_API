#  Spot+

Spot+ é uma API REST desenvolvida em ASP.NET Core para auxiliar no gerenciamento de estacionamentos, oferecendo recursos para controle de vagas, veículos, clientes e movimentações.

##  Sobre o Projeto

O Spot+ foi criado com o objetivo de modernizar a gestão de estacionamentos, proporcionando um sistema capaz de organizar informações sobre vagas disponíveis, entradas e saídas de veículos e demais operações relacionadas ao estacionamento.

##  Objetivos

- Facilitar o controle de vagas.
- Gerenciar veículos cadastrados.
- Registrar entradas e saídas.
- Organizar informações dos clientes.
- Disponibilizar uma API escalável e de fácil manutenção.

## 🛠 Tecnologias Utilizadas

- ASP.NET Core
- C#
- Entity Framework Core
- SQL Server
- Swagger/OpenAPI
